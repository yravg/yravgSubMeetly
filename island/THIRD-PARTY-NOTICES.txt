== LiveCaptions-Translator (Apache-2.0) ==
The subtitle overlay (island/docs/overlay.md) is modelled on the feature set of LiveCaptions-Translator by SakiRinn,
https://github.com/SakiRinn/LiveCaptions-Translator (colours, opacity, sentence count, click-through, pause and
copy). Only the idea is borrowed; no code.
## LiveCaptions Translator (Apache-2.0)

The list of caption translation services (Google, DeepL, Youdao, Baidu, MTranServer, LibreTranslate,
Ollama, OpenAI-compatible, OpenRouter) follows the engine list of LiveCaptions Translator
(github.com/SakiRinn/LiveCaptions-Translator, Apache-2.0). Only the idea of the feature list was used;
no source code was copied: the providers are our own implementation (engine-rs/engine/src/providers.rs).
