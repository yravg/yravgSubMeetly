Downloader add-on for Oyenza Studio: what it holds and where it comes from

yt-dlp.exe
  yt-dlp, which reads a link and downloads its video or sound. Downloaded
  from yt-dlp's own release on GitHub, unchanged. Each version of Oyenza
  Studio names the release it takes and that file's size and SHA-256
  (poni_core::addons::DOWNLOADER), and refuses any other file; a newer
  yt-dlp comes with a newer Oyenza Studio.

qjs.exe
  QuickJS-ng, a small JavaScript engine. yt-dlp runs it to answer YouTube's
  JavaScript challenges. Downloaded from QuickJS-ng's own release on GitHub
  (qjs-windows-x86_64.exe), unchanged, and saved as qjs.exe; pinned the
  same way as yt-dlp.exe.

ffmpeg.exe
  FFmpeg 9.0.2, which yt-dlp runs to join a video's picture and sound into
  one file. It is gyan.dev's official Windows build ("essentials", static,
  GPL v3), downloaded unchanged from gyan.dev's release on GitHub
  (GyanD/codexffmpeg, tag 9.0.2) as a zip, of which only bin/ffmpeg.exe is
  kept. The zip and the unpacked file are each pinned by size and SHA-256
  (poni_core::addons::DOWNLOADER), as above. It is not part of the installer.

NOTICE.txt
  This file.

They are separate programs: Oyenza Studio runs yt-dlp, and yt-dlp runs the
other two. Each keeps its own license, below.

FFmpeg 9.0.2

Used for: ffmpeg.exe.

This add-on runs a build of FFmpeg (https://ffmpeg.org) that gyan.dev
publishes (https://www.gyan.dev/ffmpeg/builds/), the "essentials" 64-bit
static build of 9.0.2. That build is configured with --enable-gpl and
--enable-version3, so it is licensed under the GNU General Public License,
version 3 (its README.txt says "License: GPL v3"), and it carries its own
copy of that licence (LICENSE in the zip). Its source is FFmpeg's, at the
commit its README.txt names: https://github.com/FFmpeg/FFmpeg/commit/946fcce07b

Oyenza Studio does not distribute this file: each PC downloads it itself,
from gyan.dev's release, when the Downloader is switched on. Oyenza Studio
starts ffmpeg.exe as a separate program and links none of it, so its own
licence doesn't change, and anyone can put another build in its place.
