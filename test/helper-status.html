Pemecahan masalah

        
Helper terputus / tidak jalan
          
Jalankan ./scripts/start-native.sh dari root repo, lalu cek curl -sf http://127.0.0.1:17865/health. Di Side Panel → Settings → Engine → Native helper → Refresh.

        
Port 17865 sudah dipakai (EADDRINUSE)
          
Ada proses lain di port itu. Hentikan helper lama via ./scripts/stop-native.sh, lalu start ulang.

        
Berkas besar gagal / tanpa ffmpeg
          
Pasang ffmpeg (brew install ffmpeg di macOS, paket distro di Linux), lalu Restart helper dari Settings.

        
Native host tidak ditemukan
          
Pasang host per OS: native/install-host.sh (macOS), install-host-linux.sh (Linux), install-host.bat (Windows) + ID ekstensi dari chrome://extensions.

        
Transkripsi lambat di CPU
          
Di Windows/Linux butuh CUDA untuk GPU; kalau tidak ada, pakai model kecil (Whisper Tiny/Base) atau alihkan ke helper di mesin ber-GPU. Lihat halaman Benchmark.
