# Materi listing Chrome Web Store

## Nama
Local TransSub

## Ringkasan singkat (132 karakter)
Subtitel & terjemahan real-time 100% on-device. Tanpa akun, tanpa cloud — audio tetap di perangkat Anda.

## Deskripsi
Local TransSub menambahkan subtitel langsung pada tab Chrome dan berkas offline:

- Transkripsi Whisper di browser (WASM/WebGPU) atau Native Helper
- Terjemahan berjenjang: Whisper-direct, Chrome Translator, Opus-MT, LLM lokal
- Overlay Shadow DOM + Side Panel
- Ekspor SRT / WebVTT / TXT
- Opsional: helper Windows/Linux/macOS untuk berkas besar & ASR lebih cepat

Semua inferensi lokal. Lihat Kebijakan Privasi di store/PRIVACY.md.
